# GlobeTrotter – Travel Planning Application

GlobeTrotter is a full-stack web application designed to manage user profiles and support future travel planning features.

---

## Tech Stack

### Frontend
- React
- Axios
- HTML
- CSS

### Backend
- Node.js
- Express.js
- Multer (for file uploads)

### Database
- MySQL

### Tools & Utilities
- Git & GitHub
- npm
- dotenv
